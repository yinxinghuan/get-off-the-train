# Crazy Games review screenshots — Get Off the Train

Captured from the guest build at devicePixelRatio 1.

- `before-*` is the default branch (`master`) Crazy Games build.
- `after-*` is `cursor/cg-train-polish-2674`.

Each size has a start frame, one tutorial step, a mid-car frame, a MADE IT card, and a MISSED IT card. 800×450 has start, made, and missed.

The result cards in this set use separate slots for the upgrade icon, name, description, rank, and a price pill. The upgrade cards fill the left column down to the same bottom edge as the ticket buttons. Miss and made cards share CAR, BEST CAR, FALLS, and BEST SCORE. Grip is a hand on a hanging strap when it can be bought, and a lock when it cannot.

`after-907-made` is a keyboard clear of car 01 (9s spare on a 15s clock). `after-907-missed` is a brand-new save's first miss. `after-907-missed-seeded` is a save where grip costs 90 and shows a lock; the other two upgrades cost 40 and show their icons. `after-907-upgrades-close` is that seeded row. `after-907-upgrades-ready` is the same row when grip is affordable, with the hand icon. `after-907-car05-made` is a keyboard clear of car 05 (3s spare on a 12s clock). Earlier car 03, car 04, and car 06 frames are still in the branch.
