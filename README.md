# Crazy Games review screenshots — Get Off the Train

Captured from the guest build at devicePixelRatio 1.

- `before-*` is the default branch (`master`) Crazy Games build.
- `after-*` is `cursor/cg-train-polish-2674`.

Each size has a start frame, one tutorial step, a mid-car frame, a MADE IT card, and a MISSED IT card. 800×450 has start, made, and missed.

The result cards in this set use separate slots for the upgrade icon, name, description, rank, and a price pill. Miss and made cards share CAR, BEST CAR, FALLS, and BEST SCORE. The two columns end on the same bottom edge.

`after-907-made` is a keyboard clear of car 01 (4s spare on a 10s clock). `after-907-missed` is a brand-new save's first miss. `after-907-missed-seeded` is a save where grip costs 90 and shows a lock; the other two upgrades cost 40 and show their icons. `after-907-upgrades-close` is that seeded row. `after-907-upgrades-ready` is the same row when grip is affordable, with the hand icon. `after-907-car03-made`, `after-907-car04-made`, `after-907-car05-made`, and `after-907-car06-made` are keyboard clears of those cars.
